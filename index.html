KUV
APISS

Une extension qui remplace quelques variantes d’un nom dans le texte des pages que vous consultez.

Le remplacement se fait localement dans votre navigateur. L’extension ne transmet pas le contenu des pages.

Télécharger pour Firefox Télécharger pour Chrome

Installation

Firefox

  1. Télécharge le ZIP Firefox et décompresse-le.
  2. Dans Firefox, ouvre about:debugging, puis « Ce Firefox ».
  3. Clique « Charger un module complémentaire temporaire » et sélectionne le fichier manifest.json du dossier décompressé.

Cette installation temporaire est à refaire après le redémarrage de Firefox.

Chrome, Brave et Edge

  1. Télécharge le ZIP Chrome et décompresse-le.
  2. Ouvre la page des extensions : chrome://extensions, brave://extensions ou edge://extensions.
  3. Active « Mode développeur », clique « Charger l’extension non empaquetée », puis choisis le dossier décompressé.

Fonctionnement

KUVAPISS parcourt les nœuds de texte d’une page et remplace les variantes configurées. Les champs de saisie, les éditeurs de texte et le code de la page sont ignorés.

Vie privée

Aucun compte, aucune analyse d’audience et aucun serveur ne sont utilisés par l’extension. Lire la déclaration de confidentialité.
